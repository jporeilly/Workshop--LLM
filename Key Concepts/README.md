# Ollama Embedding Visualization Tools

This repository contains a collection of Python scripts for exploring, visualizing, and understanding embeddings generated by Ollama using the llama3.2:latest model. Each script focuses on a different aspect of embeddings and their applications.

## Requirements

- Python 3.7+
- Ollama installed and running (with llama3.2:latest model)
- Required Python packages:
  - numpy
  - matplotlib
  - scikit-learn
  - pandas
  - seaborn
  - ollama (Python client)

## Installation

1. Install Ollama following instructions at https://ollama.com

2. Pull the llama3.2:latest model:
   ```
   ollama pull llama3.2:latest
   ```

3. Install required Python packages:
   ```
   pip install numpy matplotlib scikit-learn pandas seaborn ollama
   ```

## Scripts Overview

### 1. Basic Embedding Visualization

**File:** `embedding_visualization.py`

**Purpose:** This script demonstrates basic properties of embeddings generated by Ollama. It creates an embedding for a simple text prompt, visualizes its statistical properties, and compares similarity between related texts. This provides a foundation for understanding how embeddings capture semantic meaning.

**Key Features:**
- Generates embeddings for text using Ollama
- Visualizes embedding vector statistics (distribution, dimensions)
- Compares semantic similarity between related texts
- Creates a similarity matrix visualization

### 2. Embedding Analysis Tool

**File:** `embedding_analyzer.py`

**Purpose:** This script provides a more comprehensive analysis of embeddings, including topic clustering and visualization of embedding spaces. It demonstrates how embeddings can group semantically similar content together, even when the exact words differ, which is the foundation for many NLP applications.

**Key Features:**
- Analyzes embedding statistical properties
- Visualizes topic clustering using t-SNE dimensionality reduction
- Demonstrates semantic similarity through heatmaps
- Includes a sample semantic search implementation

### 3. Search Comparator

**File:** `search_comparator.py`

**Purpose:** This script compares traditional keyword-based search with embedding-based semantic search. It demonstrates how embedding search can find semantically related content even when specific keywords are missing, highlighting one of the most practical applications of embeddings in information retrieval.

**Key Features:**
- Implements both keyword search and vector search
- Provides side-by-side comparison of search results
- Visualizes query and documents in embedding space
- Tests different types of search queries (direct match, semantic concepts, thematic)

### 4. Transformer Demonstrator

**File:** `transformer_demonstrator.py`

**Purpose:** This script demonstrates key concepts in transformer architecture using embeddings. It visualizes token embeddings, self-attention mechanisms, transformer processing stages, and response generation to provide insights into how large language models process and generate text.

**Key Features:**
- Visualizes token-to-token attention weights
- Illustrates transformer processing stages
- Shows relationship between prompts and responses
- Provides detailed analysis of the transformer process

## Running the Scripts

All scripts follow a similar execution pattern:

1. Start your Ollama server (typically running on localhost:11434)
2. Run the script:
   ```
   python script_name.py
   ```
3. When prompted, confirm the Ollama host or enter a custom URL if needed
4. The script will generate visualizations and save them to a timestamped directory

### Example:
```
python transformer_demonstrator.py
```

- Provides visualizations of search results as bar charts

- Generates token attention heatmap showing relationships between words
- Creates a visualization of transformer processing stages
- Shows the relationship between input prompts and generated responses

- Results are saved to the `transformer_analysis` directory with timestamp
